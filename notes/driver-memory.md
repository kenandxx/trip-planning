## 1. 默认出发地与驾驶画像
- **常驻基地**：千叶县船桥市 **滝不動駅**（京成松戸線，旧新京成線）周边。
- **驾驶风格**：驾龄约 3 万公里，全程严格依赖导航（「跟着导航开车」）；偏好宽敞双车道，主动规避单行商业窄巷、无护栏陡坡盲弯、复杂多岔高架 JCT 与非必要夜间山路。
- **真实车速与排期系数（2026-11-25 实战复盘铁律）**：
  - 绝不按 Google Maps 理想 `1.00×` 排死紧凑链路！高速低于限速稳开、临时进 PA 洗手间、错过路口掉头或排队等位，实测普遍多花 **20%–35%+**。
  - **排期默认使用 `1.20×` 稳健系数**；山路 / 雨雾 / 冬季雪地默认按 **`1.35×`** 预留缓冲，并配套 `TripCopilot` 行中 3 步打卡与 Behind 自动砍项拯救。

## 2. 发车前防呆双锁（血泪教训・每次必检）
1. **Google Maps 路线选项防坑锁**：
   - 发车点开导航第 1 秒，必须进「路线选项」确认 **「避开收费公路」「避开高速公路」处于关闭状态**，且蓝色预览线上明确带有 **「有料 / 收费」** 标签及合理高速耗时（防止被静默导下东名高速钻箱根山路，单次可晚点 +90 分钟！）。
2. **ETC 与硬币杯架锁**：
   - 确认车内 ETC 读卡器绿灯常亮，并在中控杯架常备 **¥100 × 6 枚 + ¥10 × 5 枚 + ¥1,000 纸币 2 张** 应对地方非 ETC 收费道。
3. **高速 SA / PA 导航搜词铁律**：
   - 导航搜高速服务区只用 **`设施名 + 下り/上り`**（如 `EXPASA海老名 下り`、`Pasar幕張 上り`），绝不附带市町村门牌地址（否则易导去高速围栏外的地面辅路）。

## 4. 机场接送＆铁道衔接黄金套路
- **千叶侧零堵车送成田机场最优解 → `新鎌ヶ谷駅`**：
  - 从神奈川/伊豆返程走 **アクアライン → 馆山道 → 京叶道路 → 新鎌ヶ谷駅**，全程绕开东京都心堵车，送完回 **滝不動駅** 仅需 12–15 分钟。
  - 新鎌ヶ谷零换乘直达成田 T1 / T2·T3：**京成スカイライナー**（全席指定 20–22 分钟，大箱子首选）或 **アクセス特急**（免特急费刷 Suica，约 39–42 分钟）。
- **日本机场新退税＆安检液体防雷（2026年11月起）**：
  - 国际线离境须 **先去海关柜台刷护照核验免税品，再办值机托运**。
  - **布丁 / 果冻 / 明太子酱 / 花生酱膏体**（如 [[marlowe-zuyoshindo|マーロウ]] 玻璃烧杯布丁）均受 `>100ml` 液体安检限制：赶飞机的同行朋友要么车上吃掉（留空杯），要么在车站/机场塞进托运行李箱！
